# Using the terminal from iPhone and laptop

## Install on iPhone
1. Open your terminal's address in **Safari**.
2. Tap Share → **Add to Home Screen** → Add. It now opens full-screen like an app.

## Install on laptop
Chrome/Edge: open the site, click the install icon in the address bar. Safari (Mac): File → Add to Dock.

## Daily routine
1. **Sign in** with your app password and authenticator code (once per 12 hours).
2. **Connect Zerodha** each trading morning: Connections → *Log in with Zerodha*. You log in on Zerodha's own page.
   The connection is stored on the server, so connecting from one device connects all your devices.
   If the login page misbehaves inside the iPhone home-screen app, do it once in normal Safari or on your laptop.
3. The connection expires around 6 AM the next day. The status always shows when it expires.

## Fibonacci calculator
Choose NIFTY or SENSEX at the top, enter swing high, low, direction and (optionally) spot.
*Lock* freezes the anchors. *Copy* puts a plain-text table on the clipboard.
The NIFTY historical preset (24,774.30 / 22,179.90) is a reference only, not the current swing.

## Claude / ChatGPT analysis
1. AI → pick a mode → add your notes → *Build snapshot*.
2. Untick anything you don't want to share. Client IDs, emails and phone numbers are masked by default.
3. Tap *Copy + open Claude* (or ChatGPT). Start a new chat and paste.
4. Copy the reply back into **Compare** for that snapshot ID. Do the same with the other assistant.
5. Write your own thesis and *Save and lock* it. Later, record the actual outcome.
Nothing is ever sent to either assistant automatically.
